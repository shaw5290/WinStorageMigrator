# 🛠️ WinStorageMigrator

一个基于 Windows Batch (CMD) 的轻量级、无依赖、自动化系统存储迁移与目录管理工具。

专门解决 C 盘空间不足、用户目录（`C:\Users`）臃肿、项目文件离散等问题。通过 NTFS **Junction (目录联接)** 技术，无损重定向目录，同时提供强力空间清理与权限管理功能。

---

## ✨ 核心功能

1. **全量用户目录迁移与映射**
   - 自动备份原生文件/目录，并将其无损迁移至指定的次要存储盘（如 `D:` 盘）。
   - 自动生成 `mklink /J` 软链接，对上层应用与系统完全透明，保证环境路径不失效。
   - 内置黑名单过滤机制（自动跳过 `AppData`、`Start Menu` 等系统关键软链接）。
   - 内置防套娃机制（自动跳过已有 `_bak` 备份后缀及重解析点目录）。

2. **自动备份残留清理**
   - 支持分别清理源路径（C盘）与目标路径（D盘）下迁移时产生的 `_bak` 备份目录与残余垃圾。

3. **系统空间极速释放**
   - 强制夺取系统所有权，深度清理大型无用系统残留（如 `C:\Windows.old`）。

4. **高级目录提权工具**
   - 快速提权指定的系统或受限目录，一键授予管理员最高控制权限（Full Control）。

5. **开发项目脚手架与软链接工具**
   - 快速在源码盘创建真实代码目录，并在工作盘创建快捷目录联接（Junction）。

---

## 🚀 快速开始

### 准备工作

为确保 CMD 脚本在运行过程中不发生字符解码错误与语法崩溃，请严格遵循以下环境要求：

1. **保存编码**：脚本文件必须保存为 **ANSI (GBK)** 编码格式（若在 VS Code 中开发，建议配置 `"[bat]": { "files.encoding": "gbk" }`）。
2. **运行权限**：必须使用 **以管理员身份运行** 打开脚本（脚本内置权限校验机制，非管理员运行将自动跳出提示）。

### 使用步骤

1. 下载或复制代码保存为 `WinStorageMigrator.bat`。
2. 右键点击 `WinStorageMigrator.bat`，选择 **以管理员身份运行**。
3. 根据终端菜单提示输入对应数字指令（`0 - 6`）并按下回车执行。

## ⚙️ 默认参数说明

你可以在脚本顶部的 `1. 基础配置区` 自定义修改全局变量：

| 变量名 | 默认值 | 说明 |
| --- | --- | --- |
| `SOURCE_DIR` | `C:\Users\shaw` | 迁移源路径（通常为 C 盘个人目录） |
| `TARGET_DIR` | `D:\Users\shaw` | 迁移目标路径（通常为存储容量较大的分区） |
| `DIR_BAK` | `_bak` | 目录备份追加后缀 |
| `FILE_BAK` | `.bak` | 单体文件备份追加后缀 |
| `IGNORE_LIST` | `AppData "Start Menu" ...` | 忽略过滤黑名单列表（空格分隔） |

## 🛡️ 安全与兼容性设计

* **路径偏移自动修复**：脚本开头的 `cd /d "%~dp0"` 会自动纠正右键管理员启动时产生的 `C:\Windows\System32` 工作路径偏移，彻底杜绝误提权/删除系统核心文件的风险。
* **架构解耦**：摒弃复杂的嵌套 `if/else` 语法块，全部采用单向 `goto` 标签跳转逻辑，避开 CMD 传统括号转义解析 Bug。
* **文件死锁保护**：如果在迁移或备份过程中遇到文件/目录被系统占用锁死的情况，脚本会自动捕获错误并跳过，绝不强行打断整体流程。
